# Python untuk Pemula

Repositori latihan Praktikum Python untuk Pemula dari seri artikel Santrikoding, dikerjakan oleh Ajeng (SMKN 2 Subang).

## Isi

- Bab 1: Pengenalan dan instalasi Python (hello.py)
- Bab 2: Variabel dan tipe data (variabel_tipe_data.py)
- Bab 3: Operator (operator_dasar.py)
- Bab 4: Kondisi if else (kondisi_if_else.py)
- Bab 5: Perulangan (perulangan.py)
- Bab 6: Lists dan dictionaries (list_dictionary.py)
- Bab 7: Function (function_dasar.py)
- Bab 8: Class dan object (class_object.py)
- Bab 9: PIP dan virtual environments (pip_camelcase.py)
- Bab 10: Konfigurasi environment dan IDE (.vscode/settings.json, KONFIGURASI_IDE.md)

## Cara menjalankan

    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    python hello.py

Bukti hasil tiap bab ada di folder screenshots/.
